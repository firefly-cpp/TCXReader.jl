Loading and exporting

TCXReader.loadTCXFile — Function
loadTCXFile(filepath::String, csv_filepath::Union{String,Nothing}=nothing)

Load a TCX file and parse its contents. If the document contains no Activities element, the returned activity vector is empty. Present malformed non-trackpoint metadata throws an error; malformed trackpoints are warned about and skipped.

Arguments

  • filepath: The path to the TCX file.
  • csv_filepath: Optional. If provided, the parsed data will be exported to this CSV file.

Returns

  • A tuple containing the parsed TCXAuthor and a vector of TCXActivity objects.
source
TCXReader.exportCSV — Function
exportCSV(author::TCXAuthor, activities::Vector{TCXActivity}, csv_filepath::String; io=stdout)

Export parsed TCX trackpoints to a CSV file. Each row represents one trackpoint; laps without trackpoints therefore produce no rows. The existing column order and missing-value representation are preserved. A completion message is written to io.

Arguments

  • author: The TCXAuthor object containing author information.
  • activities: A vector of TCXActivity objects representing the activities.
  • csv_filepath: The file path where the CSV file will be saved.
  • io: The stream used for the completion message.

Parsing components

These functions are exported for callers that need to parse an already-open XML document or node. Most applications should use loadTCXFile.

TCXReader.parseTCXAuthor — Function
parseTCXAuthor(doc::EzXML.Document) -> TCXAuthor

Parse document-level author metadata. A missing author or missing author fields use TCXAuthor() and BuildVersion() defaults; malformed present version numbers throw an error.

source
TCXReader.parseTCXLap — Function
parseTCXLap(node::EzXML.Node) -> TCXLap

Parse a TCX Lap node. Missing start time, total time, distance, and calories use the existing TCXLap constructor defaults. Optional measurements remain nothing; malformed present numeric values throw an error. Malformed trackpoints are omitted according to parseTCXTrackPoint.

source
TCXReader.parseTCXTrackPoint — Function
parseTCXTrackPoint(node::EzXML.Node) -> Union{TCXTrackPoint, Nothing}

Parse a TCX Trackpoint node, including speed and power stored in separate activity-extension TPX elements. Missing optional measurements become nothing. If the timestamp or a present value is malformed, emit a warning and return nothing so callers can skip that point.

source
TCXReader.parseDeviceInfo — Function
parseDeviceInfo(doc::EzXML.Document) -> DeviceInfo

Parse the first activity creator in doc. Missing creator fields use the DeviceInfo() defaults; a present but invalid numeric field throws an error. loadTCXFile parses creators per activity, while this document-level method is retained for compatibility.

TCXReader.calculate_averages_and_totals — Function
calculate_averages_and_totals(lap_data::Vector{TCXLap}) -> Tuple

Calculate activity totals and unweighted trackpoint statistics. The returned 16-tuple is ordered as:

(total_time, total_distance, max_speed, total_calories, avg_hr, max_hr, avg_cadence_zero_avg_on, avg_cadence_zero_avg_off, max_cadence, avg_speed, total_ascent, total_descent, max_altitude, avg_watts_zero_avg_on, avg_watts_zero_avg_off, max_watts).

Missing cadence and power count as zero in the corresponding "zero averaging off" values. Speed uses trackpoint speed rather than lap-level speed fields, and elevation changes bridge missing samples and lap boundaries. Empty inputs return lap totals with zero for all trackpoint-derived metrics.
